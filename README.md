# 球迹（Field Atlas）

球迹是一款足球地理探索工具。选择国家或搜索球队，浏览俱乐部、城市与国家队之间的联系，从地图出发认识足球文化。

## 开始使用

打开 [球迹](https://lukezhuo666.github.io/FieldAtlas/)，点击地图上的标记切换国家，或在搜索框输入球队、城市和国家名称。选择“俱乐部”或“国家队”查看对应条目，点击球队卡片查看地点与简介。随机探索按钮会带你前往一个国家。

## 功能

- 地图标记与国家切换
- 按球队、城市和球队简介即时搜索
- 在俱乐部与国家队视图之间切换
- 随机选择地点，继续探索
- 无需账号，打开网页即可体验

球队与赛季信息为内置的精选静态样本，用于地图浏览和足球文化探索。
