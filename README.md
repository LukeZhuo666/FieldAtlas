# Fut.Map｜全球足球探索地图

**从一场具有电影感的开场出发，沿着地理空间探索国家队与俱乐部的故事。**

Fut.Map 是一款足球探索体验。它把足球信息放进可交互的世界地图中，通过动态首页、3D 地球与 2D 地图构成由宏观到局部的浏览路径，让用户沿着国家、城市和球队之间的空间联系继续发现内容。

## 为什么用地图讲足球

球队与赛事天然具有地域关系。列表适合查找已知对象，却不容易呈现足球文化如何跨越国家和城市连接起来。Fut.Map 将地理空间作为主要导航线索，让浏览本身成为一种探索过程。

## 探索路径

- **进入世界**：动态视觉开场建立整体氛围，邀请用户进入足球地图。
- **环游地球**：在 3D 地球上浏览国家队内容，先建立全球视野。
- **深入地图**：切换至 2D 世界地图，沿地区探索俱乐部与城市信息。
- **连接故事**：借助地图中的位置和视觉动效，理解球队与地域之间的联系。

## 设计重点

- 以地球和地图作为主要交互界面，减少菜单式层级。
- 通过动态转场保持从开场到信息探索的连续感。
- 用空间尺度变化连接国家队与俱乐部两类内容。

## 项目状态

当前公开版本用于体验地图叙事和交互视觉。地图飞线属于演示动效；默认展示赛季为 2024，页面数据并非实时赛事服务。

## 项目信息

- **方向**：体育内容可视化与地图探索
- **体验关键词**：空间叙事、动态视觉、全球足球、地图交互
- **技术**：Next.js、React、TypeScript、Three.js、Mapbox GL、Framer Motion
