# Fut.Map

> 从动态开场走进一颗地球，探索足球故事的空间关系。

**LukeZ 过往作品独立展示。** 这里是为报名准备的案例介绍，不包含原项目源码或素材；项目详情、协作者与贡献记录以[原项目仓库](https://github.com/eiddiedev/Fut.Map)为准。

## 项目概览

Fut.Map 是电影感足球地图：以动态首页、3D 地球和 2D 世界地图组织国家队与俱乐部的探索路径。

## 展示重点

- 动态开场建立足球世界的第一印象。
- 3D 地球用于国家队叙事，2D 地图扩展俱乐部探索。
- 公开预览是演示版本，飞线是模拟视觉效果，默认赛季固定为 2024。

## 技术与体验关键词

Next.js · React · TypeScript · Three.js · Mapbox GL
